ระบบจัดการไอเทม Blox Fruits

วิธีเปิดใช้งาน:
1. แตกไฟล์ ZIP ทั้งหมดไว้ในโฟลเดอร์เดียวกัน
2. ดับเบิลคลิก index.html เพื่อเปิดด้วย Chrome หรือ Edge
3. ใช้ปุ่มด้านบนสลับระหว่าง “จัดการไอเทม” และ “ตารางไอเทม”

หน้า “จัดการไอเทม” ใช้เพิ่ม แก้ไข ลบ ค้นหา และส่งออก/นำเข้าข้อมูล
หน้า “ตารางไอเทม” สรุปไอเทมแต่ละชนิดแบบไม่ซ้ำ พร้อมจำนวนรวมและจำนวนรหัสที่มี
ข้อมูลบันทึกใน Local Storage ของเบราว์เซอร์เครื่องนี้โดยอัตโนมัติ
แนะนำให้ส่งออก JSON สำรองข้อมูลเป็นระยะ
